# SatCHAT CLI — Releases

This repository hosts published release artifacts (wheels, macOS wheelhouses, install scripts) for the **SatCHAT CLI**.

- Source code lives on Bitbucket (`telepix/satchat-cli-demo`).
- Releases here are created automatically by the Bitbucket Pipelines release job on `v*` tags via `scripts/publish_release.sh`.

See the [Releases](../../releases) page for downloadable assets.
